# EuropeGAS - Официальный дилер в Узбекистане

Веб-сайт для официального дилера EuropeGAS в Узбекистане, предоставляющего газобаллонное оборудование (ГБО) и сервисные услуги.

## Структура проекта

- `europegas.html` - Главная страница сайта
- `css/` - Директория с CSS стилями
- `js/` - Директория с JavaScript файлами
- `images/` - Директория с изображениями

## Функции сайта

- Информация о компании и преимуществах
- Каталог продукции и услуг
- Интерактивная карта с локациями по всему Узбекистану
- Контактная информация

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Font Awesome для иконок
- Google Fonts для типографики

## Запуск проекта

Для запуска проекта достаточно открыть файл `europegas.html` в любом современном веб-браузере.
